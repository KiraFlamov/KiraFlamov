## 📂 Проекты

GitHub: https://github.com/KiraFlamov/CoffeeCRM

### ✅ Web-Tracker (Task Manager / Full-Stack)

Веб-приложение для управления задачами с авторизацией и REST API на FastAPI.

**Функционал:**
- Регистрация и авторизация пользователей (JWT + cookies)
- Создание, редактирование и удаление задач
- Сортировка задач по дате и статусу
- AJAX обновление задач (JS API endpoints)
- Защита маршрутов по пользователю
- Работа с PostgreSQL через SQLAlchemy

**Стек:**
FastAPI, SQLAlchemy, Jinja2, JWT, PostgreSQL, Python

🔗 GitHub: https://github.com/KiraFlamov/Web-Tracker

### 📝 Web-Notes (Flask Notes Application)

Веб-приложение для заметок с системой пользователей и логированием действий.

**Функционал:**
- Регистрация и авторизация пользователей (Flask-Login)
- CRUD заметок (создание, редактирование, удаление)
- Поиск и сортировка заметок
- Логирование действий пользователей (Rotating logs)
- Обработка ошибок (403, 404, 500)
- CSRF защита форм (Flask-WTF)
- SQLite база данных

**Стек:**
Flask, SQLAlchemy, SQLite, Python

🔗 GitHub: https://github.com/KiraFlamov/Web-Notes
